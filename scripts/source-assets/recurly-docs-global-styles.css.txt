/* ============================================================
   RECURLY DOCS — README NATIVE CSS
   ============================================================
   Single consolidated stylesheet for ReadMe's global CSS settings.
   Targets ReadMe's own native classes across all page types and
   UI surfaces.

   DEPENDENCY
   ─────────────────────────────────────────────────────────────
   Requires recurly-readme-theme-v8.1.css to be present in the same
   global theme. V8.1 provides the full --recurly-* color token set.
   This file adds the three tokens V8.0 didn't yet prefix, then
   uses --recurly-* throughout for consistency.

   PARTS
   ─────────────────────────────────────────────────────────────
   1 — General Articles    Shared chrome: prose links, AI dropdown,
                           copy button, pagination, date line,
                           page thumbs, dividers. Fires on both
                           Guide and API Reference.

   2 — Guide pages         h1 yellow border (guide-only), excerpt
                           subtitle, and right-hand TOC sidebar.

   3 — API Reference pages HTTP method badges, endpoint URL,
                           section headers, parameter rows,
                           response accordion, status chits,
                           and the full Playground panel.

   4 — Sidebar navigation  Shared sidebar chrome: container,
                           section headings, links, subpages,
                           expand chevron, external icon,
                           section separators.

   5 — API Reference sidebar  ID alias, QuickNav button, inline
                           method pills, page icon wrappers,
                           user avatar.

   6 — QuickNav modal      The "Jump To" search overlay.

   7 — Changelog           Full brand styling for the changelog.

   SELECTOR STABILITY NOTE
   ─────────────────────────────────────────────────────────────
   ReadMe exposes two tiers of class names:

     Stable  — prefixed with rm- (rm-Playground, rm-TryIt,
               rm-LanguageButton, rm-APIMethod, etc.).
               Primary selectors throughout.

     Hashed  — long alphanumeric suffixes generated by CSS-in-JS.
               May change between ReadMe deployments. Used only
               alongside a stable rm-* counterpart — never solo.

   All rules use !important to override ReadMe's host CSS.
   ============================================================ */
