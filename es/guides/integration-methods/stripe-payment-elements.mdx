# Descripción general

Crea una interfaz de pago totalmente personalizada con tu marca usando Stripe Payment Elements y, luego, envía un token de confirmación a la API v3 de Recurly para procesar pagos y almacenar datos de facturación reutilizables.

## Definición

Stripe Payment Elements y Express Checkout Elements te permiten crear una experiencia de pago totalmente personalizada con tu marca usando los componentes de Stripe. Envía el token de confirmación resultante a la API v3 de Recurly para procesar pagos, almacenar datos de facturación reutilizables y admitir cargos únicos y recurrentes.

<Note>
  **Disponible en todos los planes de Recurly**
</Note>

### Requisitos previos y limitaciones

- Requiere una integración funcional con la API v3 de Recurly y una configuración de Recurly.js
- Algunos métodos de pago y APM de Stripe están restringidos según el país del comercio. Si un método no aparece en tu Stripe Dashboard, es posible que el país de tu cuenta no cumpla los requisitos (por ejemplo, Revolut solo está disponible en el Reino Unido y la UE)
- Stripe Payment Links, Stripe Checkout y Radar no son compatibles con esta integración
- Cupones del 100 % y créditos de cuenta: como se requiere comunicación con la pasarela durante la configuración inicial, se recomiendan las pruebas gratuitas en estos casos para evitar fallos de pago futuros

# Detalles clave

## Funciones compatibles

Crea una solución de pago con Stripe Payment Elements o Express Checkout Elements y envía el token de confirmación resultante a Recurly mediante la API v3. Los clientes también pueden actualizar su información de facturación a través de Stripe Elements o de las soluciones existentes de Recurly: Checkout, Hosted Payment Pages o Recurly.js.

Consulta una vista previa de las capacidades de Stripe Elements en el [sitio de demostración de Stripe](https://checkout.stripe.dev/elements). Para ver todos los detalles de implementación, consulta la [guía del Developer Hub](https://docs.recurly.com/recurly-subscriptions/docs/third-party-checkout#/).
