# Definition

<div className="rp-definition">Compass Assistant is a network of agents, sub-agents, and tools accessible through a unified chat interface in Recurly. It combines conversational search across product docs, knowledge base articles, developer docs, and records; a Data Agent for generating exports; Ask AI for in-context product questions; agentic AI for taking action on plans, add-ons, and items; and code assistance — all from a single panel.</div>

- Code snippets

## ✦ Get data with the Data Agent

The Data Agent is an embedded AI agent within Compass Assistant that lets you generate async exports through natural language. Request an export, specify filters (version, time range, variations), and receive a download link — without navigating export forms or learning export schemas.

## Tips for best results

- **Be specific.** The more context you provide, the more accurate and useful the response.
- **Iterate.** If the first response isn't quite right, refine your question or ask a follow-up.
- **Use natural language.** No special commands — just ask as you would a colleague.

***

## Manage conversations

**New chat** — Select **New chat** to start a fresh conversation with its own context.


<Image src="https://files.readme.io/9fc222b5492f9f11208ab7d4b735f7f8681e2ceb4dcfe6524acfb5e008c91117-image.png" align="center" width="75%" />


**Chat history** — Open **Chat history** to view your previous conversations.


<Image src="https://files.readme.io/8ee919cd7104dbff6e22a10a3413690d1099c312986818b39fa88290fa5179e4-image.png" align="center" width="75%" />


The speech bubble icon indicates a previous conversation. Select any conversation to reload it and continue the thread. Follow-up questions will use that conversation's context.

The s-shaped icon indicates a Compass Skill and to the right is the status of the skill \[Not Started, In Progress, Complete].&#x20;

Results respect your existing permissions — you only see content you already have access to. Your chats are private and visible only to you.

# FAQs

<Accordion title="What AI models power Compass Assistant?">
  Compass Assistant is powered by Google Gemini. Learn more about [Gemini Data Governance](https://cloud.google.com/gemini/docs/discover/data-governance) and [Generative AI Governance](https://cloud.google.com/vertex-ai/generative-ai/docs/data-governance).
</Accordion>

<Accordion title="How is my data secured when used with AI?">
  Merchant data used with Recurly AI tools is stored in accordance with Recurly's Privacy Policy. AI models run on Google Vertex AI and Elasticsearch to support data security and compliance.
</Accordion>

<Accordion title="Is my data used to train AI models?">
  No. Recurly does not currently use merchant data for AI training.
</Accordion>

<Accordion title="Is my data shared with competitors?">
  No. Merchant- and subscriber-level data is never shared with competitors. Only aggregated, non-identifiable insights may be used for analytical or benchmarking purposes.
</Accordion>

<Accordion title="How do I opt out of Recurly Compass?">
  Contact [support@recurly.com](mailto:support@recurly.com) to opt out.
</Accordion>
